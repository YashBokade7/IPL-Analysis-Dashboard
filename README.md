# IPL Analysis Dashboard | Power BI

## 📌 Project Overview
This project presents an **interactive Power BI dashboard** designed to analyze **Indian Premier League (IPL) data from 2008 to 2025**.  
The dashboard enables users to explore **team and player performance, season-wise outcomes, and tournament statistics** through dynamic visuals and filters.

---

## 🎯 Business Objective
To build an interactive analytics solution that provides insights into:
- Team performance across IPL seasons
- Season winners and runners-up
- Player achievements and key match statistics
- Dynamic points table based on official IPL rules

---

## 📊 Key KPIs & Metrics

### 🔹 Primary KPIs
- Winner Team of selected season (with dynamic team logo)
- Runner-Up Team of selected season (with dynamic team logo)

### 🔹 Secondary KPIs
- Total Matches Played  
- Total Teams Participated  
- Total Sixes & Fours  
- Total Centuries & Half-Centuries  
- Total Venues Used  

### 🔹 Season Statistics
- **Orange Cap**: Top run scorer, runs scored, team, player image  
- **Purple Cap**: Top wicket taker, wickets, team, player image  
- **Top Fours & Sixes**: Player-wise boundary leaders  

### 🔹 Points Table
Dynamic season-wise points table including:
- Team Logo & Name  
- Matches Played, Won, Lost, Tie, No Result  
- Total Points calculated using IPL rules  
  *(Points = Wins × 2 + Ties × 1 + No Result × 1)*

---

## 🗂️ Datasets Used
- `ipl_matches_data.csv` – Match-level details  
- `ball_by_ball_data.csv` – Delivery-level data  
- `players-data-updated.csv` – Player information  
- `teams_data.csv` – Team metadata
